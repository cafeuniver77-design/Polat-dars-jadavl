NORMUROZ JONBOLATNING DARS JADVALI

Bu PWA (bosh ekranga o‘rnatiladigan web-ilova) paketi, APK emas.
Ishlatish uchun papkadagi fayllarni HTTPS hostingga joylang. So‘ng Android Chrome’da saytni oching:
⋮ > Install app / Add to Home screen > Install.

Birinchi ochishda internet kerak; keyin fayllar keshlanib, offline ishlashi mumkin.
A/B guruhga tegishli jadvaldagi noaniq qatorlar ilova ichida ogohlantirish bilan belgilangan.
